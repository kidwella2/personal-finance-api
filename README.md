# personal-finance-api

## Repository layout

- `code/api/` contains the API, its runtime files, and setup instructions.
- `code/api_tests/` contains the API test runners.
- `code/nginx.conf` configures NGINX for the API.
- `presentation/` is reserved for presentation materials.
- `plan/todo.md` contains the current code TODO.
- The original `stage1/` source tree is preserved.

The acceptance criteria will be added to `acceptance.md` later. See
`code/api/README.md` for setup and run instructions.
